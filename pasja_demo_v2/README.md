# PASJA demo V2

To jest druga, bardziej dopracowana wersja demonstracyjna.

## Co zostało poprawione
- mocniejsza, bardziej charakterystyczna identyfikacja PASJA
- bardziej editorialowy hero
- ręcznie wyglądające akcenty
- ticker / pasek marki
- nowy układ menu
- asymetryczna galeria
- mocniejszy blok opinii
- lepszy kontakt i lokalizacja
- animacje wejścia
- sticky mobile bar: Zadzwoń / Menu / Trasa
- usunięty czarny pasek demo z góry

## Uruchomienie
Otwórz `index.html`.

## GitHub Pages
1. Utwórz repo np. `pasja-demo-v2`
2. Wrzuć `index.html`, `styles.css`, `script.js`
3. Settings → Pages
4. Deploy from a branch → `main` → `/ (root)`
5. Zapisz
